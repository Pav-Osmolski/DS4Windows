Locally built from the clean recorded commit using Go 1.27.2, Release tags,
CGO disabled and trimmed paths. This is not a GitHub release-workflow binary.
Graceful closing applies only after completed management replies, bounded by
250 ms and 4097 drained bytes and interruptible by server shutdown. Controller
and audio streams, authentication, encrypted framing and operation retries are
unchanged. No experimental diagnostic server or comparison switches are included.

Thanks to @cns00 for five captures in DS4Windows issue 66. The isolated original
method failed 77/400 requests versus 3/400 with graceful closing on that laptop.
Residual resets remain. No hardware fault or universal resolution is claimed.

All dependency versions/checksums match 0.1.13. Complete dependency grants,
GPL, systray modification notices and WDL notices are preserved. Only the
top-level VIIPER version label in the license report is updated. These Windows
packages are unsigned and require maintainer acceptance before stable release.
