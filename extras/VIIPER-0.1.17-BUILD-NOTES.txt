This is the clean tagged Windows amd64 Release-workflow executable, not a local
rebuild. Expose the existing DualShock 4 microphone capture status through the
narrow microphone-interface endpoint for every DS4 registration alias, including
the audio companion used with Xbox output. DS4Windows can detect when Windows
opens the microphone and arm the physical Bluetooth microphone route. Existing
input/output and controller connection ownership are preserved. Paired
DS4Windows release: 5.0.50.

API regression tests cover actual registered full DS4, duplex V3 and audio-only
duplex V3 implementations, exact-device selection, inactive/active transitions,
queued PCM delivery and status reads that do not consume audio.

Full GPL/dependency grants, systray modification notices and WDL attribution
are retained byte-for-byte from the release package. Windows/Linux tests, lint,
generated-client checks and cross-platform builds gate the release. The Windows
executable is unsigned. No universal hardware/game compatibility is claimed.
