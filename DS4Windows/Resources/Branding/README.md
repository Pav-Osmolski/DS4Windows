# Sidebar artwork

The maintainer supplied these five transparent PNGs in
`DS4Windows-icon-set.zip` on 19 October 2026. The image bytes are unchanged;
resource filenames omit the archive's numeric prefixes.

The catalog order is Blue Tile (first and default), Midnight Circle, Blue Frame,
Controller and Angular Badge. Blue Tile was numbered 02 in the source archive;
that numbering does not define the display order or persisted values.

Keep the 1254 × 1254 source resolution and transparency. WPF displays the
selected image at 60 × 60 device-independent pixels with uniform scaling and
high-quality resampling. The frozen image sources are reused by the sidebar
and Settings previews. Windows taskbar/title-bar and tray icons have separate
resources and settings.
