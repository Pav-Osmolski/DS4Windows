# About artwork

`about-banner.png` is an AI-assisted adaptation of the maintainer-provided
`DS4Windows-Promo.png`, prepared with the built-in image-generation tool on
20 October 2026. The original supplied artwork is retained outside the repository.

The edit removes baked-in lettering and recomposes the controller and blue/violet
waveforms into a wide banner with a clear left-hand area. Application headings,
version and other text are real WPF controls so they remain accessible and sharp
with display scaling. The image is decorative and is not used to represent
controller compatibility or connection status.
